# ゆらぎ — 見た目のテーマ

## アイコン: 手描きの「あ」

製品アイコンは、鉛筆で手描きした「あ」を写真から取り出して輪郭にしたもの。
フォントの輪郭は使っていない。

言語バーには英語・中国語・韓国語などの入力方式が並ぶので、ひと目で日本語用と分かること、
小さくても迷わず読めることをいちばんに置いた。

## アイコンの形

- 「あ」を枠いっぱいに大きく、まっすぐ置く。切らない、揺らさない、傾けない、飾りを足さない。
  台座ありでも字は台座いっぱい（高さ約 94〜97%）。ダークのタスクバーでは墨の台座が背景に溶け、
  見えるのは字だけなので、台座の中に余白を取ると字が小さく見える。
- 字は手描きの形そのまま。写真から輪郭を取るときに線を約 25% 太らせた。
  ほかに加えているのは拡大縮小と位置合わせ、それと小サイズの線の太らせだけ。
- 全サイズで同じ輪郭を使う。ただしタスクバーに出る 16・20・24px だけは、細い鉛筆の線が
  軽く見えないよう、線を外側へ太らせる（16・20px で 0.5px、24px で 0.625px。`build.py` の `GROW`）。
  16・20・24px は、太らせた線も含めて枠に収まる最大の高さで、線がいちばんくっきり出る位置に
  画素単位で合わせてある。

## 見た目の決まりごと

| 項目 | 内容 |
|---|---|
| 色 | 墨 `#111111` と白 `#ffffff` の 2 色だけ。中間調・グラデーション・差し色は使わない |
| 字 | 手描きのひらがな 1 字（「あ」）。全サイズ同じ輪郭（16〜24px は線を太らせる） |
| 字の扱い | 形を変えない。切らない、曲げない、ぼかさない、二重にしない、縦横比を変えない |
| 余白 | 要素を足さない。字だけ（波線や水面の線は描かない） |
| 言葉 | 設定画面などの文言も、柔らかい和語を優先する（例: 「同時打鍵のゆるさ」） |

## ファイル

| ファイル | 用途 |
|---|---|
| `yuragi.ico` | **既定。明暗両用。** 墨の角丸台座に白い「あ」。明るいタスクバーでは台座ごと、暗いタスクバーでは白い字が見える |
| `yuragi-light.ico` | 明るいタスクバー専用（台座なし・墨の字）。暗い背景では見えない |
| `yuragi-dark.ico` | 暗いタスクバー専用（台座なし・白い字）。明るい背景では見えない |
| `src/yuragi*.svg` | 元データ。`<名前>.svg` が原図（64 単位、32px 以上に使用）、`<名前>-16px/20px/24px.svg` が画素合わせ版 |
| `src/glyph.json` | 字の輪郭（手描きの「あ」、全サイズ共通）。`build.py` が読む |
| `build.py` | 寸法表と字の輪郭から SVG・.ico・preview.png をまとめて生成（`python3 build.py`、Pillow のみ必要） |
| `preview.png` | 確認用。各アイコンを明るい背景／暗い背景に実寸と拡大で並べたもの |

各 .ico には 16 / 20 / 24 / 32 / 40 / 48 / 64 / 256 px が入っている
（表示倍率 100〜300% に対応。256 のみ PNG 圧縮、ほかは 32bit BMP + マスク）。

## ゆらぎでの使いどころ

使っているのは明暗両用の `yuragi.ico` だけ。どれもこの場所のファイルを直接参照するので、
`build.py` で作り直せば、次のビルド（とインストール）でそのまま入れ替わる。

| どこに | どうやって |
|---|---|
| 入力方式の切り替え一覧（TSF のプロファイル） | `src/tip/yuragi_tip.rc` で DLL に `IDI_YURAGI` として入れ、`RegisterProfile` に DLL のパスと `-IDI_YURAGI` を渡す。反映は登録し直したとき |
| `yuragi-broker.exe` のアイコン | `src/broker/broker.rc` に `IDI_YURAGI` として入れる |
| 設定ウィンドウ（ゆらぎ 設定）の窓アイコン | `yuragi/ime/admin_ui.py` が `iconbitmap(default=...)` で読む。インストール先はソースの木をそのまま展開したものなので、同じ相対位置にある |

使っていないところ:

- 言語バーの「ゆ/Y」はモード表示で、`yuragi_tip.cpp` の `GetIcon` が実行時に字を描く。製品アイコンとは別。
- ブローカーの通知領域のお知らせは、システムの情報/警告アイコンのまま。
- 台座なしの `yuragi-light.ico` / `yuragi-dark.ico` は、どこにも組み込んでいない。

## 形を変えたいとき

`build.py` 冒頭の寸法表（`SMALL` と `MASTER`）と、小サイズの線の太らせ量（`GROW`）を直して
実行し直す。寸法表で決めるのは字の高さ `h`、上端の位置 `top`、横の寄せ `gx` の 3 つだけ。
`GROW` を変えたら、太らせた線も枠に収まるよう `SMALL` を探し直す。
SVG と .ico は同じ表から出るので、片方だけずれることはない
（SVG では太らせた分を同じ色の縁取り `stroke-width` で表す）。

字の輪郭（`src/glyph.json`）は手描きの線から取ったもの。太さは `GROW` で変える。

## 字の輪郭の出どころ

「あ」の輪郭は手描き。フォントの輪郭は含まない。
