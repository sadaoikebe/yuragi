# 記録するだけの入力プログラム

InputMethodKit の入力プログラムに何が届くかを、実機で記録する道具。結果は [docs/MACOS.md](../../../../docs/MACOS.md) §9。

## 中身

| ファイル | 中身 |
|---|---|
| `main.swift` | 入力プログラム `YuragiProbe`。届いたイベントと、イベントの監視で見えたキーを `~/Library/Logs/yuragi-probe/imk.jsonl` に JSON の行で書く。既定ではキーを食べずに通す |
| `Info.plist` | 入力ソースの定義。ひらがな（`…YuragiProbe.Japanese`、アイコン「ゆ」）と英字（`…YuragiProbe.Roman`、アイコン「Y」）の 2 モード |
| `icon.swift` | メニューバーのアイコン（1 文字）を作る |
| `build.sh` | `out/YuragiProbe.app`（簡易の署名）と `out/ctl` を作る。`ctl`（入力ソースの登録・有効化・選択。`ctl list｜register <アプリ>｜enable <ID>｜disable <ID>｜select <ID>｜current`）とアイコンの道具の元は `src/mac/` |
| `install.sh` | 作って `~/Library/Input Methods/` に置き、2 つのモードを有効にする。有効にならないときは、システム設定で 1 度追加する（MACOS.md §6.3） |
| `uninstall.sh` | 入力プログラム、記録のフォルダ、「入力監視」の許可の記録を消す |
| `session.py` | 記録を 1 回採る。プローブを選び、人が打つのを待ち、ABC に戻して、採れた分を表示する |

## 使い方

Xcode（`swiftc`）が要る。

```sh
cd tools/keyprobe/mac/imk
./install.sh
python3 session.py                                  # 届くイベントを記録する（キーは通す）
python3 session.py --tap                            # イベントの監視も記録する（初回は「入力監視」の許可を求める）
python3 session.py --mark --commits Terminal,Safari # 変換中の文字へのアプリの答えを記録する
python3 session.py --show                           # 記録を表示するだけ
./uninstall.sh
```

- `session.py` は、最後のイベントから 8 秒（`--quiet`）で終わる。`--commits` を付けると、挙げたアプリがそれぞれ 2 回確定した 2 秒後に終わる。何も届かなければ 60 秒でやめる。
- 合成したキーは、1 つ上のフォルダの `out/probe app io.github.yuragi.inputmethod.YuragiProbe.Japanese "<キー>"` で入れる（[../README.md](../README.md)）。合成したキーはイベントの監視には出ない。

| `session.py` の引数 | 動き |
|---|---|
| （無し） | 届いたイベントを記録して通す |
| `--mark` | 文字キーを変換中の文字（でたらめなかな）にし、Return で確定、Esc で消す。アプリの答え（選択範囲、変換中の範囲、文書の長さ、左の文字が取れたか、位置、受け付ける属性）を記録する |
| `--tap` | 「入力監視」の許可を求め、イベントの監視（解放、実際の時刻、キーボードの種類、送り元のプロセス）を記録する |
| `--eat-modes` | 英数・かな を食べる |
| `--chars` | キーの文字と、左の文字そのものも記録する |

引数は、`~/Library/Logs/yuragi-probe/` に置く空のファイル（`mark`、`request-tap`、`eat-modes`、`chars`）として入力プログラムに伝わる。入力プログラムは、アプリが使い始めるときと打鍵のたびに、このファイルの有無を見る。

## 記録の読み方

`session.py` の表示は 1 イベント 1 行。

| 項目 | 中身 |
|---|---|
| `handle`／`tap` | InputMethodKit に届いたイベント／イベントの監視で見えたイベント |
| `down`・`up`・`mods` | 押下・解放・修飾キーの変化 |
| `code` | キーコード |
| `kb` | キーボードの種類（`handle` では常に 0） |
| `t` | イベントの時刻（起動からの秒） |
| `srcpid` | 送り元のプロセス（0 は本物のキーボード） |
| `leftOK` | 左の文字が、直前に確定した文字で終わっているか |

リピートは数だけを表示する。

## 注意

| 注意 | 理由 |
|---|---|
| 採り終えたら入力ソースを戻す（`session.py` は ABC に戻す） | 選んでいる間、打ったキーのキーコードと時刻が記録に残る（`--chars` では文字も残る） |
| プロセスを止めるのは、ほかの入力ソースを選んでいる間にする（`install.sh` はそうする） | 選ばれている間に止めると、OS は起動し直さず、動いていたアプリは開き直すまでつながらない |
| 記録を空にするときは、プロセスを止めてからファイルを消す | 動いているプロセスは、消したファイルに書き続ける。切り詰めると、元の位置に書き続けて先頭が空のバイトで埋まる |
| 作り直したら、「入力監視」の許可を採り直す（`install.sh` が古い記録を消す） | 簡易の署名はビルドごとに別のアプリと見なされ、許可が外れる。古い記録が残っていると、OS は許可を求める表示を出さない |
| イベントの監視は、許可があるときと `--tap` のときだけ作る | 許可が無いまま作ると、OS が許可を求める表示を出す |
| 人に打ってもらう前に、合成したキーで記録に行が増えることを確かめる | つながっていないと、打っても何も起きない |
