# ゆらぎの使い方

インストールの1行は [README](../README.md) にあります。この文書は、使い始めたあとに読むものです。

## 打ち方

ゆらぎは、US 配列（ANSI）のキーボードで NICOLA-A の親指シフトを打つ IME です。

親指キーはスペースバーだけです。左右どちらの親指で押しても、キーボードからは同じに見えます。
文字キーとスペースバーを同時に押すと、親指シフトの文字になります。
左右どちらの文字だったかは、変換のときに前後の文脈から決めます。

親指は、専用の親指シフトキーボードと同じように、左右を使い分けて打ってください。
速く打って、片方の親指が上がる前に反対の親指でスペースバーを押しても、打ち間違いではありません。
スペースバーが押されたままの間は左右が交互だったと分かるので、変換はむしろ正確になります。
片方の親指だけで打つと、この手がかりが無くなり、変換の精度が落ちます。

たとえば「既読」と「記憶」のように、左右の違いで両方とも正しい語になる場合は、
両方を候補に並べます。違う方が出たら、候補から選び直してください。

打っている間も、変換した結果が下線つきで表示されます。
Space を押すと候補窓が出て、候補を選び直せます。

### 句読点・数字・記号

数字と記号は全角で入ります。半角が欲しいときは、変換して ← / → で記号や数字の文節に移り、Space で候補を開きます。

| 記号 | 打ち方 |
|---|---|
| 、 ， 。 ． ・ | `[` ／ P ／ Q ／ Z ／ `/`（どれも単独） |
| ー | X と Space |
| 「 」 | `4` ／ `5` と Space |
| 『 』 | `[` ／ `]` と Space |
| （ ） | `9` ／ `0` と Space、または Shift |
| ！ | Shift+`1` |
| ？ | `1` と Space、または Shift+`/` |
| ： ； | Shift+`;` ／ `'` と Space |
| ～ … ― | `` ` `` か `3` と Space（`` ` `` は Shift でも）／ `=` と Space ／ `-` と Space |
| － ＝ ￥ ’ ” | `-` ／ `=` ／ `\` ／ `'`（どれも単独）／ Shift+`'` |

- 数字キーと Space を同時に押すと記号になります（`1`〜`0`: ？／～「」［］＊（））。
- Shift を押すと、キーの上段に書いてある記号の全角になります（Shift+`2` は ＠）。
- `]` を単独で押しても、何も入りません。
- 読みから記号を出せます。「きごう」「やじるし」「まる」「さんかく」「ほし」「あるふぁ」などを打って変換すると、
  未学習なら候補の4番目から記号が並びます（最初の3件は普通の変換候補で、表示も普通の変換のまま）。
  文節の読みが記号の読みとちょうど同じときだけ出るので、助詞が付いた形（やじるしを）では出ません。
  その場合は Shift+← で文節を縮め、Space で文節を変換してから、もう一度 Space で候補を開きます。選んだ記号は学習され、次に同じ読みで変換すると候補の1番目に出ます
  （「かっこ」で「」を選ぶと、次からは「」が1番目）。ほかの記号の並び順は変わりません。その記号の上で Ctrl+Delete を押すと忘れます。

### 押しっぱなし

キーを押しっぱなしにすると、同じ文字が繰り返し入ります。親指と同時に押したままなら、
同じ親指の文字が続きます（「のののの」）。Space だけを押しっぱなしにすると、入力が無ければ全角の空白が続き、
入力があれば変換して次の候補へ進み続けます。

## キー操作

### 入力中（変換する前）

| キー | すること |
|---|---|
| Space（単独で押す） / Shift+Space | 変換して、候補窓を出す |
| Space / Shift+Space（入力が無いとき） | 全角／半角の空白を入れる |
| Enter | 表示のとおりに確定する |
| Backspace | 最後の1打を消す |
| Esc | 入力をすべて消す |
| Ctrl+Space / Ctrl+Shift+Space | 半角／全角の空白を入力に足す（変換中なら、確定してから空白で次の入力を始める。入力が無いときは Ctrl+Shift+Space で全角の空白を入れる） |
| Tab | 続きの候補を出す（入力の予測）。候補が無ければ何もしない（入力はそのまま）。予測の候補窓が開いていれば次の候補 |
| F6〜F10 | 変換してから、下の「変換中」と同じ字種に変える |
| Shift+英字 | 一時的な英数入力（確定するまで続く） |

一度に変換できるのは 200 打までです。それを超えた打鍵は入りません（いったん確定するか、変換して Ctrl+↓ で前から確定してください）。

#### 一時的な英数入力

かなを打っている途中で Shift+英字を打つと、その英字が半角の大文字で入り、そこから先は Shift を離しても
半角の英数字が続きます。この間は、キーボード全体が US 配列の英数入力として働きます。
英字・数字・記号のどのキーも、刻印の文字が半角で入ります（Shift を押せば刻印の上段。Shift+`1` は !）。

- 続いている間は、同時打鍵は効きません（数字キーと Space の「 なども出ません）。Space は変換です。
- Enter で確定、Esc で取り消し、Backspace で英数の並びを全部消すと終わります。直接入力への切り替えでも終わります。
- 同じ入力の途中でかなに戻るには、英数の並びを Backspace で消し切るか、先に確定します。

### 変換中

| キー | すること |
|---|---|
| Space / Shift+Space | 候補を開いて次／前の候補へ |
| ↓ / ↑（候補窓が開いているとき） | 次／前の候補へ |
| PgDn / PgUp | 候補の次の9件／前の9件 |
| 1〜9 | 候補窓の番号の候補を選ぶ |
| ← / → | 前／次の文節へ移る |
| Shift+← / Shift+→ | 文節を1打ぶん縮める／伸ばす |
| Home / End | 候補窓が開いていれば先頭／最後の候補へ。変換中に閉じていれば先頭／末尾の文節へ |
| Enter | 全部を確定する |
| Ctrl+↓ | 先頭の文節だけを確定する（部分確定） |
| そのまま次を打つ | 今の変換を確定して、次の入力に移る |
| Esc / Backspace | 候補窓が開いていれば閉じる（変換はそのまま）。閉じていれば変換をやめて、変換する前の入力に戻る |
| F6 | 今の文節をひらがなにする |
| F7 | 今の文節をカタカナにする |
| F8 | 今の文節を半角カタカナにする |
| F9 | 打ったキーを全角英数にする |
| F10 | 打ったキーを半角英数にする |
| Ctrl+Delete（候補窓が開いているとき） | 今選んでいる候補の学習を忘れる |

補足:

- F6 と F7 は、続けて押すと、左右の読み違いのひらがな／カタカナを順に出します。
  左右を取り違えた読みを、ここで直せます。
- F9 と F10 は、続けて押すと、小文字 → 大文字 → 先頭だけ大文字、と変わります。
- 入力が無いときの F6〜F10 と Tab は、アプリのキーとして働きます。
- 文節を移ると候補窓が閉じます。Space で新しい注目文節の候補を開きます。
- 文節を伸縮すると候補窓が閉じ、変わった文節が読みで表示されます。この間は ↑ / ↓ でも縮める／伸ばすことができ、Space / Shift+Space で読みの文節を変換します。Enter を押すと表示どおりに確定します。

#### 部分確定

変換中に Ctrl+↓ を押すと、先頭の文節を1つだけ確定します。確定した文節は文書に入り、残りは未確定のまま残るので、
続けて直したり変換したりできます。押すたびに前から順に確定し、最後の文節まで確定すれば Enter と同じです。
例: 「今日は良い天気ですね」を変換して Ctrl+↓ を押すと「今日は」が確定し、「良い天気ですね」が残ります。

- 残りの文節は選んだ候補も文節の区切りもそのままです。候補窓が閉じ、注目が残りの先頭に移ります。
- 先頭が Shift+英字で入れた英数の並びなら、その並び全体を1つとして確定します。
- 確定した文節のうち、候補を選び直したものは、その場で学習されます（Enter の確定と同じ）。
- 入力の予測の候補窓が開いている間は、何もしません。
- 入力が無いときは、アプリの Ctrl+↓ として働きます。

### 直接入力への切り替え

| 操作 | すること |
|---|---|
| `` Alt+` ``（Esc の下、1 の左のキー） | かな入力と直接入力を切り替える |
| タスクバーの「ゆ」「Y」をクリック | 同上 |
| タスクバーの「ゆ」「Y」を右クリック | メニューから切り替える |

ほかの IME との切り替えは Win+Space です。

切り替えのキーは、`%USERPROFILE%\.yuragi-ime\tip.json` で変えられます。
たとえば次のように書きます（`toggle_vk` は Windows の仮想キーコード。192 が ` のキー）。
アプリを開き直すと反映されます。

```json
{"toggle_vk": 192, "toggle_mods": ["alt"]}
```

## 候補窓

変換すると、入力位置の下に候補窓が出ます。

- 1ページに9件まで出ます。番号のキーで選べます。
- 候補の最後には、ひらがなとカタカナの候補もあります。
- 候補を選び直したり文節の区切りを変えたりして確定すると、学習されます。出たまま確定したものは学習しません。
- 学習したものは、同じ文節の後では次から先頭に出ます。そうでない場所では、言語モデルがその表記を選ばなかったときだけ、
  最後に選んだものが先頭に出ます（言語モデルが動いていなければ、いつも最後に選んだものが出ます）。

## 設定ウィンドウ

タスクバーの「ゆ」「Y」を右クリックして「設定を開く」で開きます。タブは4つあります。

### 単語登録

自分の単語を登録します。入力が無いときに Ctrl+F7 を押すと、このタブで開きます。読み・単語・品詞を入れて「登録」を押します。
一覧で選んで「選択を削除」で消せます。登録した単語は、次の変換から効きます。

### 学習

学習した内容の一覧です。検索もできます。

- **選択を忘れる**: 選んだ変換を、次から先頭に出さないようにします。
- **選択を単語登録**: 選んだ変換を、単語として登録します。学習を消しても残ります。

### 設定

設定できる項目が、名前・今の値・説明つきで並んでいます。選んで書き換えるか、「既定に戻す」を押します。
項目は 3 つです:

- 学習: 学習する／使わない
- 入力の予測: Tab キーで出す／使わない
- 言語モデル（読みと直前に確定した文から、変換の結果を選ぶもの。zenz-v2.5）: 使う／使わない。使わないときは、辞書だけで変換します

変更は、変換エンジンを再起動すると反映されます（「状態」タブのボタン）。

### 状態

変換エンジンの状態、辞書が壊れていないか、学習した変換と登録した単語の件数、ファイルの場所を表示します。
「変換エンジンを再起動」のボタンもここにあります。

## 困ったとき

### 「ん」が「＝」になる（配列がひとつずれている）

次のように入るときは、Windows のキーボードの設定が「日本語キーボード（106/109 キー）」になっています。

| 打ったつもり | 入った字 | 例 |
|---|---|---|
| ん | ＝ | 「かもしれません」→「かもしれませ＝」 |
| っ | … | 「メッセージ」→「目…セージ」 |
| 、 | ｀ | 「今、」→「今｀」 |

ひとつ右のキーを押すと「ん」「、」が出るので、配列がずれたように見えます。
US 配列のキーボードを日本語版の Windows につないだときに、よく起こります。

直し方:

1. 設定 → 時刻と言語 → 言語と地域 を開きます。
2. 「日本語」の右の「…」→「言語のオプション」を選びます。
3. 「キーボード レイアウト」の「レイアウトを変更する」で「**英語キーボード（101/102 キー）**」を選びます。
4. Windows を再起動します（再起動するまで変わりません）。

### タスクバーに「!」が出た

日本語変換が止まっています。入力済みの文字は、そのまま残っています。

1. 「!」を右クリックして「**もう一度試す**」を押します。
2. 直らなければ、インストールの1行（[README](../README.md)）をもう一度実行してください。
   学習した内容と登録した単語は残ります。

止まったときは、Windows の通知にも1回出ます。通知を押すと「もう一度試す」と「記録のフォルダを開く」
（記録（ログ）を見られます）が出ます。止まっている間にかなを打とうとすると、入力位置の下にも
「日本語変換が止まっています。タスクバーの「!」を右クリックしてください」と出ます。

### 準備中（薄い「ゆ」）

サインインの直後や、変換エンジンが起動し直している数秒の間は、「ゆ」が薄く表示されます。
この間に打ったキーは、日本語に変換されずにそのまま（英字で）入ります。準備ができると、変換されるようになります。
この間も `` Alt+` `` で切り替えられます（直接入力にすると薄い「Y」）。切り替えたモードは、準備ができたあとも続きます。

### いつも「Y」のまま

管理者として動いているアプリなど、一部のアプリでは日本語変換を使えません。
そのアプリでは「Y」のままで、英字がそのまま入ります。

## 更新

インストールと同じ1行を、もう一度実行します（[README](../README.md)）。

- アプリは開いたままで構いません。
- 取得するのは、変わったものだけです。
- 途中で失敗しても、それまでの版がそのまま動きます。もう一度実行すると、続きから進みます。
- 学習した内容・登録した単語・設定は、そのまま引き継ぎます。
- 更新の前から開いていたアプリも、そのまま使えます。

## アンインストール

[README](../README.md) の1行を実行します。入っている版は自動で見つけます。

- 管理者の確認が1回出ます。アプリは開いたままで構いません。
- 使用中で消せなかったファイルは残ります。登録は外れているので使われません。アプリを閉じたあとに削除できます。
- 学習した内容・登録した単語・設定（`%USERPROFILE%\.yuragi-ime`）は残ります。
- これらも消すときは、README の「全部消す場合」の1行（`-RemoveData` 付き）を実行します。消す前に、場所と大きさを表示して確かめます。
- 途中で止まったとき（管理者の確認を取り消したときなど）は、もう一度実行すると続きから進みます。

置き場所と手順の細かいところは [DESIGN.md](DESIGN.md) の「置き場所」と「インストール・更新・アンインストール」にあります。

## データの置き場所

| 場所 | 中身 |
|---|---|
| `%USERPROFILE%\.yuragi-ime\` | 学習した内容、登録した単語、設定、記録（ログ） |
| `%LOCALAPPDATA%\yuragi-ime\` | 変換エンジンと、それを動かす Python、辞書、言語モデル |
| `%ProgramFiles%\yuragi-ime\` | Windows に組み込む部分（アプリの中でキー入力を受け取る部分と、ゆらぎの常駐プログラム） |
