# JIS 106 のキー配置と既定の割り当て

標準 JIS 106 の全 106 キーと、MS-IME プリセットの局面別の動作を定義する。実装手順は [JIS.md](JIS.md)。

## 1. 表の読み方

- E・D・C・B は数字段から下への順。`Scan` は Set 1 の make コード、`VK` は Windows の仮想キーコードまたは NLS の基底値。数値はいずれも 16 進。設定では基準の刻印をキー名として使い、修飾を `Shift+;` のように付ける。[Windows のスキャンコード表](https://learn.microsoft.com/ja-jp/windows/win32/inputdev/about-keyboard-input) [WDK の kbd106.c](https://github.com/microsoft/Windows-driver-samples/blob/main/input/layout/fe_kbds/jpn/106/kbd106.c)
- **—** は出力のない文字面。**無操作** は打鍵を消費して未確定文字列と候補窓を保つ。**通す** はその打鍵による確定やモード変更をせずに Windows／アプリに渡す。**確定して通す** は確定後に同じ打鍵を渡す。**独立** はそのキーを親指キーとの同時打鍵に使わず、親指キーは独立して単独打鍵を判定する。**親指キー** は Space・無変換・変換で、文字キーとほぼ同時に押すと親指シフトになり、そのキーだけを押すと本来の機能になる。
- 文字面はコンソーシアムの J 型図を基準にする。C11 `:` と C12 `]` では J 型の空欄面を使う。FMV-KB232 の後退・取消にあたる操作は、標準 JIS の `←`・`Backspace`・`Esc` に置く。[J 型配列図](https://web.archive.org/web/20250521224017/http://nicola.sunicom.co.jp/spec/j.gif) [NICOLA 配列規格書 §3](https://web.archive.org/web/20210508080709/http://nicola.sunicom.co.jp/spec/kikaku.htm#0103) [富士通の親指シフト専用機資料](https://docs.fujitsu/documents/1-0019/japanist-relatedproducts.pdf)

## 2. 文字・記号キー（48 キー）

単独、親指左、親指右、小指 Shift は、かな入力時の出力。親指面に二つの候補があるときは、Space と文字キーの同時打鍵から両方を変換候補に残す。無変換との同時打鍵は親指左、変換との同時打鍵は親指右に決まる。片側だけならその文字を、両方同じならその記号を出す。両面が空欄で同時打鍵に参加するキーは、成立した同時打鍵を無操作とする。英数欄は Caps Lock オフでの出力。

### 文字面の適用規則

- C01 の `ゔ` は J 型で選択可能な面として採用する。D10 の `，` は U+FF0C、B01 の `．` は U+FF0E、B10 は `・`。D12 の `゛`（U+309B）と `゜`（U+309C）は独立した文字として入力し、直前のかなは保持する。[NICOLA 配列規格書 §3](https://web.archive.org/web/20210508080709/http://nicola.sunicom.co.jp/spec/kikaku.htm#0103) [JIS 化提案 §5.3](https://web.archive.org/web/20220516223927/http://nicola.sunicom.co.jp/spec/jisdraft.htm)
- C11 `:`、C12 `]`、B11 `\` の修飾なしは無操作で、Space から独立する。単独面がある D11 `@`、E03、E10～E13 は同時打鍵の判定に加える。親指面が空欄の同時打鍵と `Shift+0` は無操作。親指面が空欄の同時打鍵に使った Space は消費し、単独の変換や空白に振り替えない。
- かな入力中の小指 Shift は英大文字を半角で（Caps Lock がオンなら小文字。続く英字と同じ）、記号を全角で入れる。半濁音は親指面で入力する。半角・全角英数入力中にはそれぞれの英数列を使い、英字の通常／Shift は Caps Lock がオンのときだけ反転する。直接入力は Windows が文字を出す。[JIS 化提案 §5.2–5.3](https://web.archive.org/web/20220516223927/http://nicola.sunicom.co.jp/spec/jisdraft.htm)
- `¥` と `\` は半角で U+005C、全角でそれぞれ `￥`（U+FFE5）と `＼`（U+FF3C）。F9/F10 ではかなトークンの元キーから英数を引き、入力済みの記号は幅を変える。円記号キー由来の U+005C は再度全角にするときも `￥` に戻す。[WDK の英数面](https://github.com/microsoft/Windows-driver-samples/blob/main/input/layout/fe_kbds/jpn/106/kbd106.c#L275-L295)

### FMV-KB232

富士通 FMV-KB232 は、Windows からは日本語キーボード（`kbd106`）に見える。キーボードの名前は `kb232`、かなの表は `data/nicola_j_kb232.json`。ドライバでは標準 JIS と見分けられない。

KB232 では `@` と `:` のキーが移設されている。移設されたキーは、移設先の位置のコードではなく、そのキー本来のコードを送る。A 段の `;` の右には、小指に近い順に後退（`VK_BACK`）・取消（`VK_ESCAPE`）・`＠` が並び、`：` は Q 段の `P` の右に上がっている。標準 JIS の表のままだと `＠` で `、` が入るので、次の 2 キーだけを変える。ほかのキーと面は上の表と同じ。

| 刻印 | Scan / VK | 単独 | 親指左 | 親指右 | Space 同時打鍵 | 小指 Shift | 半角英数 通常／Shift | 全角英数 通常／Shift |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `@` | `1A / C0` | `＠` | — | — | 独立 | `｀` | `@` / `` ` `` | `＠` / `｀` |
| `:` | `28 / BA` | `、` | — | — | 無操作 | `＊` | `:` / `*` | `：` / `＊` |

- `＠` は同時打鍵に加えず、かな入力で全角の `＠` を入れる（かなの表の `literals`）。
- `:` は標準 JIS の D11 `@` の面（単独 `、`、親指面は空欄）を持ち、同時打鍵に加える。
- `]`（`2B / DD`）は標準 JIS と同じく無操作で独立のまま。標準 JIS で `]` がある A 段右端の位置は KB232 では後退・取消・`＠` が占め、`DD` を送るキーは確認されていない。
